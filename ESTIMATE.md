Prepared 15 November 2026. These figures are a suggested developer quote in INR for this scope, not a provider price, invoice, or commitment from the client.

| Included work | Example allocation |
| --- | ---: |

Assumes one static marketing/portfolio page, supplied and approved media, English content, the existing section structure, one final set of company/contact details, a Docker preview image, and the prepared GitHub Pages pipeline. Allow approximately **3–5 working days** for content finalization, client feedback, and launch from an approved direction; client response times are additional. No development payment or purchase has been initiated.

Docker is supplied for preview/portability; GitHub Pages hosts the public static output. Any additional work needs a separate scope and price.

Before publishing: finish the local website review, replace the dummy email, and clear its placeholder flag.
